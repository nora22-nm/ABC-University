# ABC University

## Description

ABC University is a web-based University Management System developed using ASP.NET MVC 5, C#, Entity Framework, and SQL Server. The system provides an easy and efficient way to manage students, teachers, courses, and classrooms.

## Features

- Student Management

- Teacher Management

- Course Management

- Room Management

- Create, Read, Update, and Delete (CRUD) operations

- User-friendly interface

## Technologies Used

- ASP.NET MVC 5

- C#

- Entity Framework

- SQL Server

- HTML5

- CSS3

- Bootstrap

- JavaScript

## Project Structure

- **Controllers** – Handles user requests and application logic.

- **Models** – Contains data models and database context.

- **Views** – Contains the user interface pages.

- **Content** – CSS and static resources.

- **Scripts** – JavaScript libraries and files.

- **Migrations** – Database migration files.

## How to Run

1. Open the solution in Visual Studio.

2. Restore the NuGet packages.

3. Configure the SQL Server connection string in `Web.config`.

4. Update the database using Entity Framework Migrations.

5. Run the project.
